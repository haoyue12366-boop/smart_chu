# Windows 离线部署说明

当前为 Windows 开发运行包，正式数据、全量评估及公网联调以验收记录为准。Windows AMD64，锁定 Python 3.12、后端 wheel、知识与策略；前端是预先构建的 Vue 静态文件，部署运行无需 Node。包内包含后端 Python 源码、前端运行文件、100 道菜的固定知识快照、离线依赖和部署/接口/技术说明。比赛接口为 `POST /api/competition/plan?task_id=任务标识`，主体直接使用 `name`、`id` 数组，分钟保留一位小数。

将部署 ZIP 解压到独立安装目录，用 PowerShell 执行：

本次 `SmartCooking-Windows-20261007-PS51-fix` 修订修复系统 Windows PowerShell 5.1 对中文脚本的读取兼容问题：四个部署脚本采用带 BOM 的 UTF-8，支持系统 PowerShell 和 PowerShell 7。旧 `SmartCooking-Windows-20261007.zip` 的检查使用 PowerShell 7，未覆盖系统 PowerShell 5.1，不能据此认定旧包在 5.1 下可安装。请将修订包解压到新的独立目录，按下面相同命令安装；所有修订文件都已纳入新包清单，启动仍核对文件哈希。

```powershell
& .\windows\Install.ps1
& .\windows\Start.ps1 -Port 8000
```

等待 `http://127.0.0.1:8000/health/ready` 返回就绪后，核验与停止命令为：

```powershell
& .\windows\Verify.ps1 -Port 8000
& .\windows\Stop.ps1
```

安装使用包内 Python、uv 和按 `uv.lock` 核对哈希的 wheel，命令指定离线与禁止索引访问。不能把包内 `environment` 复制到其他路径；移动安装目录后从原始 ZIP 在新目录重新安装。原始包不带环境目录、`.env`、运行库或模型日志。

默认监听 `127.0.0.1`，浏览器访问 `http://127.0.0.1:8000/`。状态默认保存在安装目录的 `state/`，启动可通过 `-StateDirectory` 指定独立目录；安装、停止和重新启动保留已提交状态。停止脚本检查 PID、启动时间和可执行路径后终止 API 及其求解子进程，随后重新启动会按 SQLite 事实恢复，不自动完成未确认工序。

知识文件只读、策略和所有文件均绑定交付清单；启动前核对哈希。在线初排、重排、就绪检查不依赖 Neo4j。知识维护仍在独立环境进行，重新发布必须生成新版本。自然语言入口默认关闭；项目已经完成的真实供应商连接证据单列，不把密钥打入部署包。

策略以包内 `policy.json` 为准。2026-10-07 用户授权的新默认为 `p6-quality-v2`：初排共享预算 7000ms（5 秒内为优秀），重排共享预算 5000ms；目标依次为五分钟内集中出菜、减少总人工、缩短总流程。新包的启动脚本明确指向包内策略。已有会话绑定原策略，不能通过重启自动替换。其他历史交付包仍使用各自原策略，不随本次打包变化。手动或设备反馈仍须明确完成和释放，模拟时钟不能证明真实完成。
